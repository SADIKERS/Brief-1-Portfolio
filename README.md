# 🌐 Portfolio — Abdelilah Sadik

Bienvenue sur mon portfolio personnel ! 👋

Ce projet a été réalisé dans le cadre du **Brief 1** de ma formation en développement web chez YouCode. Il présente mon parcours, mes compétences, mes projets et mes objectifs professionnels à travers une interface moderne et responsive.

## 📌 À propos du projet

L'objectif de ce projet est de concevoir et développer un portfolio personnel à partir d'une maquette Figma, en utilisant les fondamentaux du développement web.

Le design repose sur un thème sombre, des accents cyan et une interface claire, avec une attention particulière portée à la lisibilité, à l'organisation du contenu et à l'expérience utilisateur.

## 📄 Pages du portfolio

Le site comprend quatre pages principales :

- **Accueil** : présentation personnelle, profil et liens vers mes réseaux professionnels.
- **À propos** : parcours, compétences techniques et objectifs professionnels.
- **Projets** : présentation de quatre projets réalisés ou prévus dans le cadre de mon apprentissage.
- **Contact** : coordonnées, réseaux sociaux et formulaire de contact.

## 🛠️ Technologies utilisées

- **HTML5** — structure et contenu des pages.
- **CSS3** — mise en page, styles et responsive design.
- **Flexbox & CSS Grid** — organisation des éléments et des cartes de projets.
- **CSS Variables** — gestion des couleurs et des styles communs.
- **Figma** — conception de la maquette.
- **Git & GitHub** — gestion de versions et partage du code.

> Ce projet est développé sans JavaScript, conformément aux exigences du brief.

## 🚀 Lancer le projet

1. Clonez le dépôt GitHub.
2. Ouvrez le dossier du projet dans Visual Studio Code.
3. Ouvrez `index.html` avec l'extension **Live Server**.
4. Consultez les différentes pages à travers la navigation.

À travers ce projet, je souhaite renforcer mes compétences en :

- Structuration de pages web avec HTML sémantique.
- Création de mises en page avec Flexbox et CSS Grid.
- Utilisation des variables CSS et des bonnes pratiques de style.
